# Dataset with Scoring - Categorized v4

This directory contains two files, each with additional scoring columns and specific modifications:

## New Columns

Both files include the following four new columns:

- `depression_score`
- `anxiety_score`
- `stress_score`
- `das_score`

## File-Specific Modifications

1. **Numeric File**:
    - The `major` column is not present.
    - The `major_category` column has been converted to integers.

2. **Other File**:
    - Retains all original columns along with the new scoring columns.

These modifications aim to enhance the dataset for better analysis and categorization.
